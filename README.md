# Twitch Chat Window packages (legacy)

This custom pacman repository no longer receives updates. Linux is now distributed as an **AppImage**, and Windows as an **EXE**.

Download the current app from the **[main application release](https://github.com/780APM/twitch-chat-window/releases/latest)**. The Linux AppImage adds itself to application-menu search on first launch and includes the fullscreen-overlay fix for KDE Plasma 6 or newer.

Older signed package assets remain available for existing installations. Previous users can remove the app-specific pacman repository using the **[migration instructions](https://github.com/780APM/twitch-chat-window#previous-pacman-installations)**. Historical setup instructions remain in this repository's git history.
